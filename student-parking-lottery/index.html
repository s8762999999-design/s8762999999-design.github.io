車位與抽籤範圍

本版執行單一同資格池的等機率抽籤。需優先、多池、不同權重或逐筆放棄遞補時，會列為另外需要確認／開發的規則；系統不判定學生資格。

STEP 02

        操作說明、範圍與技術依據

        建議行政流程

        1. 需求填寫：由承辦彙整資格、名額、缺席、遞補、異議與留存規則。
        2. 簽辦：先核定規則；名單截止且人工審查後鎖定快照，將驗證碼附於簽呈或核定附件。
        3. 現場：主管與見證人核對相同快照，執行一次完整排名。
        4. 留存：當場匯出及列印，由承辦、主持、見證簽名。

        本版適用範圍

        支援單一同資格池、正備取排序及停車位配對。優先池、多池、加權、多次抽籤資格與逐筆放棄遞補須另行設計；本版不會替學校決定政策，也不會自動寄出公文或結果。

        靜態頁面無法獨立阻止跨分頁重抽、提供可信時間或不可竄改紀錄。請勿將驗證碼視為資安認證或數位簽章。

        亂數與雜湊依據：MDN Web Crypto、W3C Web Cryptography API。以 getRandomValues、拒絕採樣及 Fisher–Yates 產生無放回排名。軟體測試檢查實作，不等同獨立資安稽核。版本 1.0.0 · 2026/10/21。

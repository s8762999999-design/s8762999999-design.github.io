# 學生停車位抽籤工作台

版本：1.0.0｜2026-10-21｜臺灣繁體中文

用途：高職行政端先釐清需求、產生簽呈草稿、鎖定經人工審核的名單與規則，供主管現場抽籤及留存紀錄。這是靜態瀏覽器工具，不代表學校已核准或完成資安驗收。

公開網站：https://s8762999999-design.github.io/student-parking-lottery/

## 五個操作步驟

1. **需求探明**：填案件、資格、時程、放棄／缺席、異議、留存與見證方式。未定事項勾「待主管確認」。車位代碼每行一個；備取人數須為非負整數。需要優先池或多池時，本版不能執行正式模式，應另行設計。
2. **公文草稿**：依表單產生草稿及待裁示清單，可複製、下載 TXT 或列印；承辦仍須走校內公文流程。本頁不會送出公文。
3. **名單鎖定**：匯入 UTF-8 CSV、檢核並鎖定。名單欄位為 `student_id,class_name,full_name`，學號是唯一識別，同名可保留；保留前導零。最多 2,000 人、CSV 1 MB。鎖定後產生完整 SHA-256；將相同驗證碼納入核定附件。
4. **現場抽籤**：主持與見證人核對人數、車位及完整驗證碼，勾選三項確認。演練可先熟悉；「已登錄核准」模式須填文號、日期及核准附件的相同驗證碼，並完成其他條件。登錄不是核准真偽驗證。按一次後產生完整排名，前 K 人按鎖定車位順序配位，其次 W 人列備取。
5. **匯出留存**：下載遮罩公告 CSV、行政完整 CSV 及完整稽核 JSON，列印後由承辦／主持／見證簽名。完整檔案含學生個資，僅供有權限者留存。

可先按「載入示範」，內含 30 位虛擬學生、10 個車位及 5 個備取。示範來源不能在同一案件升為正式，請「開始新案件」後準備行政資料。

## 公平性與範圍

- 單一同資格池、無權重、每人一次、無放回排名。預先核配者須由承辦人工排除。資格判斷不由程式代行。
- 使用 Web Crypto `getRandomValues`、拒絕採樣及 Fisher–Yates；抽籤紀錄保存選擇序列，可重播核對配位及雜湊一致性。
- 名單、規則、核准資料與當次核對項目綁在同一筆抽籤紀錄。取消須填操作人與原因，歷史保留於本頁及匯出稽核包。
- 雜湊、重播和操作鏈只檢查資料一致性，不能證明真實核准、隨機來源、可信時間、未曾重抽或不可竄改。重寫整份檔案及重新計算雜湊仍可能通過一致性檢查。
- 重新整理、另開分頁或跨裝置可重新開始。本版沒有伺服器權限、跨裝置防重抽、不可變更日誌或電子簽章。正式作業請搭配校內審核、現場見證及即時匯出簽章。
- 不支援優先／多池／加權抽籤，也不自動辦理個別放棄與後續遞補。備取名次供人工依核定規則處理。

## 個資與公開範圍

- 公開 repository 只有工具程式、操作文件與合成測試資料，未包含真實學生名單。
- 網頁沒有後端、分析追蹤、外部字型或第三方程式；名單留在瀏覽器記憶體，不自動提交 GitHub，也不自動保存。開啟網站本身仍會向 GitHub 請求頁面。重新整理前請匯出。
- 遮罩姓名與學號後仍可能辨識個人，班級仍會顯示；公告範圍與遮罩政策須經學校確認。投影模式強制遮罩並隱藏行政欄位。
- 完整 CSV 與稽核 JSON 含完整名單。不得放到公開 GitHub、公開雲端或未授權收件者。試算表對 CSV 公式的處理有差異；本版有轉義防護，未完成 Excel 重存／重開的實機驗收。

## 檔案與維護

- `index.html`：可獨立使用的完整成品，CSS 和 JavaScript 已內嵌。以 HTTPS 網站使用為建議方式；本機直接開啟時 Web Crypto 支援依瀏覽器而異。
- `template.html`、`style.css`、`core.js`、`app.js`：維護來源。
- `build.py`：以 Python 執行後產生 `index.html`。
- `core.test.cjs`：以 Node.js `node --test core.test.cjs` 執行核心測試。
- `AI_WORKFLOW.md`：實際 AI 參與、檢查紀錄與尚未驗收項目。

# 校園車證隨機分配

選擇 .xlsx，核對偵測到的名冊與車證號，再按「隨機分配車證號」，完成後下載 Excel。

- 名冊的「班級、學號、姓名」須在同一標題列，三欄的資料依原列保留。「車證號」可以使用另一個標題列、同一個標題列或另一張工作表。
- 以 Excel 的實際車證號為來源。車證充足才開始配對，多出的號碼保留未分配。重複的學號或車證號會提示修正。
- 識別欄使用 Excel 文字或單純的補零數字格式。若 Excel 已將學號或車證號開頭的零移除，網站無法推回原本的零。
- 使用同站 JSZip 處理 XLSX 容器，並沿用上層核心的 Fisher–Yates 與 Web Crypto。資料只在分頁記憶體中處理，重新整理會清空。頁面封鎖網路資料請求。
- Gemini 3.1 Pro 提供語意 HTML 與匯入、預覽、洗牌和匯出流程大綱。Claude Sonnet 5.5 審查介面規劃，建議標題列位置、錯誤狀態、觸控尺寸、鍵盤焦點和匯出文字儲存。Codex 依實際 Excel 版型實作，驗證並發佈。外部模型僅收到通用需求。
